## 🚀 Cómo ejecutar el juego

### Usuario final

1. Descarga el ZIP del juego.
2. Extrae el contenido en cualquier carpeta.
3. Haz doble clic en el ejecutable (`CatCafe.exe`).

El juego arranca en modo ventana (**1280x768**) directamente en el menú principal.

> En el repositorio también se incluyen las builds `TFG_FINAL.exe` (Windows) y `TfgFinalLinix.x86_64` (Linux).

### Desarrolladores (abrir el proyecto en Unity)

1. Clona el repositorio:
   ```bash
   git clone https://github.com/Kopolog/CatCafe-TFG.git
   ```
2. Abre **Unity Hub** → *Add* → selecciona la carpeta clonada.
3. Instala la versión del editor que indique `ProjectSettings/ProjectVersion.txt` (Unity Hub te lo ofrecerá automáticamente).
4. Abre el proyecto y carga la escena principal desde `Assets/`.
